Kebijakan Privasi OFM

Orias Financial Management · Terakhir diperbarui: Agustus 2026

OFM adalah aplikasi manajemen keuangan pribadi. Kebijakan ini menjelaskan data apa saja yang dikumpulkan aplikasi ini, bagaimana data tersebut digunakan, dan bagaimana kamu bisa mengontrolnya.

Data yang Dikumpulkan

  • Akun (jika login): alamat email dan kata sandi terenkripsi, diproses melalui Firebase Authentication (Google).
  • Data transaksi keuangan: catatan pemasukan, pengeluaran, transfer, saldo akun, kategori, dan nominal yang kamu masukkan sendiri ke aplikasi.
  • Foto struk (opsional): jika kamu melampirkan foto struk pada transaksi.
  • Mode Tamu: jika kamu menggunakan aplikasi tanpa login, seluruh data disimpan hanya di perangkatmu sendiri (local storage) dan tidak dikirim ke server manapun.

Bagaimana Data Digunakan

  • Data akun dan transaksi digunakan semata-mata untuk menjalankan fungsi aplikasi (menyimpan dan menampilkan catatan keuanganmu, sinkronisasi antar perangkat).
  • Data disimpan di Firebase (Google Cloud Firestore) menggunakan aturan akses yang membatasi setiap pengguna hanya bisa mengakses datanya sendiri.
  • Aplikasi ini tidak menjual atau membagikan data pribadi kamu ke pihak ketiga mana pun, termasuk untuk keperluan iklan.

Penyimpanan & Keamanan

Data akun tersimpan di infrastruktur Firebase milik Google, yang menerapkan enkripsi saat transit dan saat disimpan. Komunikasi antara aplikasi dan server dilakukan melalui HTTPS.

Kontrol & Hak Kamu

  • Kamu bisa menghapus transaksi atau akunmu kapan saja langsung dari dalam aplikasi.
  • Kamu bisa berhenti menggunakan mode akun dan beralih ke Mode Tamu jika tidak ingin data tersimpan di server.
  • Untuk permintaan penghapusan data secara menyeluruh, hubungi kontak di bawah.

Pihak Ketiga

Aplikasi ini menggunakan layanan Firebase (Google) untuk autentikasi dan penyimpanan data. Google memproses data ini sesuai Kebijakan Privasi Google.

Perubahan Kebijakan

Kebijakan ini bisa diperbarui sewaktu-waktu mengikuti perkembangan fitur aplikasi. Perubahan akan dipublikasikan di halaman ini.
